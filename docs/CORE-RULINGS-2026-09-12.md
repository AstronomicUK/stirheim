# Core rules decisions — 12 September 2026

## Tracker #193: minimum characteristics and overlapping recovery

Tom explicitly confirmed:

1. “Keep the current limits.” Preserve the existing characteristic-specific minimums; do not adopt the community FAQ's alternative zero-stat effects.
2. “Keep it concurrent.” Overlapping recovery periods run at the same time. A one-game absence overlapping a three-game absence requires three games of recovery, not four.

These are approved app policies resolving the source ambiguity, not claims that the official rulebook expressly defines either policy. Claude was notified through the shared session bus (message `fa32b153`) to finish verification and update #193. Do not mark implementation verified solely on the strength of this decision.

## Healing Herbs: reusable by default, optional single-use house rule

Tom explicitly confirmed: “RAW should be unlimited use, but add a house rule option to make them single-use.”

The default is reusable Healing Herbs, retaining all printed restrictions on when and how they can be used. Add an opt-in campaign house rule that consumes one dose when actually used. Selecting or previewing the action must not consume inventory. Actual uses and any corrections must remain recorded, with consumption persisted when the house rule applies.

This resolves the outstanding Healing Herbs use-limit question. Claude has been notified to implement the setting and coordinate battle-sheet integration with Codex.
